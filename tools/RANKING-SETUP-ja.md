# 共有ランキング セットアップ（永田塾）

## 1. Google スプレッドシート

1. [Google スプレッドシート](https://sheets.google.com) で **新規作成**
2. **拡張機能 → Apps Script**
3. `コード.gs` を開き、中身を **すべて削除**
4. このフォルダの `ranking-appscript.gs` を **丸ごとコピー＆貼り付け**
5. **保存**（プロジェクト名は「英語ランキング」などでOK）

### 「無題のプロジェクト」だけで作った場合

スプレッドシートに紐づいていないと動きません。

- **おすすめ**: 手順どおりスプレッドシートから Apps Script を開く  
- どうしても単体プロジェクトの場合: スプレッドシート URL の  
  `https://docs.google.com/spreadsheets/d/【ここがID】/edit`  
  の ID を `SPREADSHEET_ID = "..."` に入れる

## 2. デプロイ

1. **デプロイ → 新しいデプロイ**
2. 種類: **ウェブアプリ**
3. **次のユーザーとして実行**: 自分  
4. **アクセスできるユーザー**: **全員**
5. **デプロイ** → **Web アプリの URL** をコピー

コードを直したあとは、必ず **新しいデプロイ**（新バージョン）にする。

## 3. 動作確認（ブラウザ）

URL の末尾に付ける:

```
?action=leaderboard&lessonId=test&secret=
```

`{"ok":true,"rows":[...]}` なら成功。`bad_request` はパラメータ不足。

## 4. アプリ側（自動）

本番: **https://english-lesson-pwa.vercel.app/**

- `data/ranking-config.json` に URL が入っている
- 起動時に各 iPad へ **自動設定**（古い URL も上書き）
- **プレイヤー名**を「Player 1」以外にする
- **単語テスト全部正解** または **文法テスト完了** で  
  **「ランキング（共有）」** が表示される

URL を変えたときは `data/ranking-config.json` を更新して Git push（Vercel が反映）。

## 5. トラブル

| 症状 | 対処 |
|------|------|
| 共有ランキングを取得できませんでした | Apps Script を **新しいデプロイ**、アクセス **全員** |
| この端末だけ表示 | プレイヤー名が Player 1 のまま → 名前を変更 |
| スプレッドシートに行が増えない | スプレッドシート紐づけ or `SPREADSHEET_ID` を確認 |
